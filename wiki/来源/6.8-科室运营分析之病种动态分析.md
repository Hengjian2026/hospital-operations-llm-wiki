## 核心内容

### 动态条形图的价值

分析报告中的图表特征：
1. **涉及排序、对比**：直观给出分析结论
2. **分析报告是整体全貌**：多维度反映专题全貌
3. **图文并茂**：视觉化增强信息传递

动态条形图（如网上流行的"省会城市 GDP 排行榜"）非常直观地展示各科室的排名变化。

### DRG/DIP 背景下的应用

对各科室近月度的 **CMI、成本、费用、平均住院日**（时间消耗指数、费用消耗指数）进行动态比较：

> 静态报表只能反映当前状态；动态比较则能发现某科室从"倒数第一爬上来"的进步。

### 样例数据（23个外科科室 × 24个月）

| 字段 | 说明 |
|------|------|
| 年月 | 时间标识 |
| 病区 | 科室名称 |
| CMI | 病例组合指数 |
| DRGS组数、总权重 | 规模指标 |
| 病例数 | 服务量 |
| 平均费用、平均药费、耗材费 | 费用指标 |
| 平均住院日 | 效率指标 |
| 费用消耗指数、时间消耗指数 | 效率指标 |
| 低/中低风险死亡率 | 质量指标 |

### R 语言动态条形图要求

> 使用 R 语言生成各科室 CMI 动态变化趋势条形图，要求：
> 1. 按月份逐帧播放，每月份按 CMI 降序排列
> 2. 添加平滑过渡动画，帧率 3-5 帧/秒
> 3. 输出 GIF 图片，尺寸 800×600 像素
