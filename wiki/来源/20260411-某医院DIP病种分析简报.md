# 核心内容摘要

1. **数据概况**: 2757病种，30,840病例，总费用2.4亿元
2. **CMI分析**: CMI均值0.92，高CMI病种(>2)主要为疑难重症
3. **费用结构**: 药品费均值1252元，耗材费均值906元，检查费均值1477元
4. **DIP分值执行**: 病案分值均值80.33，标准分值均值91.65，平均差异-11.32
5. **医保类型对比**: 城乡医保24987例(81%)，职工医保5853例(19%)

# 优化建议

1. **药占比控制**: 对超过30%的病种进行用药合理性评估
2. **耗材管理**: 建立高值耗材使用审批制度
3. **住院天数管理**: 对超14天病例进行路径优化
4. **病种结构优化**: 重点发展CMI高、分值执行好的优势病种
