# 核心内容摘要

1. **BI系统局限**: 静态数据无法展示变化趋势，需要二次分析
2. **动态条形图价值**:
   - 直观展示排序、对比
   - 展示全貌，多维度分析
   - 视觉直观，图文并茂
3. **应用场景**: 科室CMI、成本、费用、平均住院日等指标的时间维度动态比较
4. **洞察发现**: 静态报表只能看当前表现，动态比较可发现"从倒数第一爬上来"的科室

---

# 动态条形图特点

| 特点 | 说明 |
|------|------|
| **排序变化** | 每时间段按指标值降序排列 |
| **过渡动画** | 平滑过渡，避免画面跳跃 |
| **逐帧播放** | 按时间顺序从第1个月到第N个月播放 |
| **直观排名** | 便于观察排名变化 |

---

# 核心指标

| 指标 | 说明 |
|------|------|
| CMI | 病例组合指数 |
| DRGS组数 | 覆盖病组数量 |
| 总权重 | 服务总量 |
| 病例数 | 患者数量 |
| 平均费用 | 住院均次费用 |
| 平均药费/耗材费 | 费用明细 |
| 平均住院日 | 住院时长 |
| 费用消耗指数 | 相对区域平均费用 |
| 时间消耗指数 | 相对区域平均住院日 |
| 低/中低风险死亡率 | 质量指标 |

# R语言 GIF 绘制要求

```r
# 核心要求
1. 基于'年月'、'科室'、'CMI'字段绘制
2. 每帧展示所有科室的CMI数值，条形长度对应CMI值
3. 按时间顺序逐帧播放（从第1个月到第24个月）
4. 每月份内按CMI值降序排列
5. 添加平滑过渡动画
6. 标题'各外科科室近24个月CMI变化趋势'
7. 副标题动态显示当前月份（如'当前月份：2022年01月'）
8. 输出GIF，尺寸800×600像素，帧率3-5帧/秒
```
