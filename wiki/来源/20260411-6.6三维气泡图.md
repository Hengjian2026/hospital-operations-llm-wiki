# 核心内容摘要

1. **升级背景**: 波士顿矩阵是二维图形，三维气泡图可在三维空间展示病种运营情况
2. **三维设置**:
   - X轴：CMI（越高越好）
   - Y轴：时间消耗指数（越小越好）
   - Z轴：费用消耗指数（越小越好）
   - 气泡大小：DRG组数
3. **科室分类**:
   - **明星科室**: CMI高 + 收支结余为正
   - **金牛科室**: CMI低 + 收支仍为正
4. **工具**: R语言 + plotly 绘制交互式三维散点图

---

# 核心指标说明

| 指标 | 计算公式 | 理想方向 | 说明 |
|------|----------|----------|------|
| DRG组数 | 本科室年度覆盖的DRG数量 | ↑ 多 | 覆盖病种越广，服务能力越综合 |
| CMI | Σ(DRG权重×病例数)/总病例数 | ↑ 高 | 疑难权重越高，技术难度越大 |
| 时间消耗指数 | 本科室DRG平均住院日÷区域平均 | ↓ 小 | <1表示住院日短、周转快 |
| 费用消耗指数 | 本科室DRG平均费用÷区域平均 | ↓ 小 | <1表示花钱少、成本低 |

# R语言 plotly 绘制要求

```r
# 加载必要的包
library(readxl)
library(dplyr)
library(plotly)

# 读取Excel数据
df <- read_excel("6.6.三维气泡图.xlsx", sheet = "Sheet1")

# 转换数值类型
df <- df %>% mutate(
  DRG组数 = as.numeric(DRG组数),
  CMI = as.numeric(CMI),
  时间消耗指数 = as.numeric(时间消耗指数),
  费用消耗指数 = as.numeric(费用消耗指数)
)

# 创建交互式三维散点图
p <- plot_ly(
  data = df,
  x = ~CMI,
  y = ~时间消耗指数,
  z = ~费用消耗指数,
  color = ~位置,
  colors = "Set2",
  size = ~DRG组数,
  sizes = c(1, 15),
  type = "scatter3d",
  mode = "markers"
)
```

---

# 图形解读

1. **气泡位置**: 反映科室在CMI、时间消耗、费用消耗三个维度的表现
2. **气泡大小**: 表示DRG组数（服务广度）
3. **颜色分类**: 按"位置"（科室类型）着色区分
4. **交互功能**: 鼠标悬停显示详细信息
