# 核心内容摘要

1. **理论基础**: 帕累托图以意大利经济学家帕累托命名，基于"二八原理"
2. **核心价值**: 识别"关键少数"问题，集中资源解决最重要的问题
3. **图形结构**: 由条形图+累积百分比线组成
   - 左侧纵坐标：频数
   - 右侧纵坐标：累积频率
4. **典型应用**:
   - 重复出入院科室分析
   - 不良事件类型分析
5. **PDCA循环**: 计划→执行→核查→分析，持续改进

# D3.js 帕累托图制作要求

1. **柱状图**: 展示频数分布，柱子上方标注数值
2. **折线图**: 展示累计比例，用圆点标记，数据点旁标注累计比例（保留两位小数）
3. **标题**: "重复出入院主要科室分布帕累托分析"
4. **坐标轴**: X轴为类别名称，Y轴左侧为数值，右侧为累计比例
5. **布局调整**: 类别多时旋转X轴标签避免重叠
6. **完整HTML代码**: 带中文注释，可直接在浏览器运行

# 管理应用

- **重点科室**: 血液、干部两科室即可解决主要问题
- **不良事件**: 医嘱错误事件占比最高（43.5%），需重点改进
- **PDCA循环**: 发现问题 → 制定计划 → 执行改进 → 检查效果
