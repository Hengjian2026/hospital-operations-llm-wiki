## 核心内容

### 旭日图简介

旭日图（Sunburst Chart）相当于多个饼图的组合，但饼图只能体现一层数据的比例情况，而旭日图不仅能体现数据比例，还能体现数据层级之间的关系。旭日图的本质是树状关系，因此也被称为**极坐标下的矩形树图**。

**核心应用场景**：从汇总到明细的层层下钻（drill-down），实现数据溯源。

### 分析示例：医保病种分层结构

数据维度：**医疗付费方式 → 倍率情况 → DIP 名称**

| 层级 | 示例 |
|------|------|
| 第一层 | 医疗付费方式（城乡医保、职工医保） |
| 第二层 | 倍率情况（正常倍率、低倍率、异常倍率） |
| 第三层 | DIP 名称（如：疥疮-保守治疗、不稳定性心绞痛-药物洗脱冠状动脉支架置入等） |

### 样例数据

10 条 DIP 病种样例数据，涵盖：
- 皮肤自体致敏-保守治疗（异常倍率）
- 疥疮-保守治疗（正常倍率）
- 动脉硬化性心脏病-冠状动脉造影（正常倍率）
- 不稳定性心绞痛-保守治疗（正常倍率）
- 不稳定性心绞痛-支架置入（职工医保，低倍率）
- 肛门脓肿-保守治疗（职工医保，低倍率）
- 血管通路装置的调整和管理-保守治疗（职工医保，正常倍率）
- 姑息性医疗-保守治疗（城乡医保，正常倍率）
- 椎基底动脉综合征-保守治疗（城乡医保，异常倍率）
- 颈动脉瘤-脑血管造影（职工医保，正常倍率）

### 工具与代码

使用 **R 语言 + Plotly** 实现交互式旭日图：

```r
library(readxl)
library(dplyr)
library(plotly)
library(viridis)

# 数据预处理
summary_data <- data %>%
  group_by(`医疗付费方式`, `倍率情况`, `DIP名称`) %>%
  summarise(病例数 = n(), .groups = 'drop')

# 创建分层结构
# 第一层：医疗付费方式
# 第二层：倍率情况
# 第三层：DIP名称

# Plotly 旭日图
fig <- plot_ly(
  data = all_nodes,
  ids = ~id, labels = ~label, parents = ~parent_id, values = ~value,
  type = 'sunburst',
  branchvalues = 'total',
  hovertemplate = "<b>%{label}</b><br>病例数: %{value}<br>占比: %{percentParent}<br><extra></extra>"
)
```

**特点**：`plotly` 可以展示交互效果，支持点击下钻。

## 关键洞察

- 旭日图适用于**医保结算单数据**的多层级分类展示
- 支持从"医疗付费方式 → 倍率情况 → 病种"三层结构的层层下钻
- 结合 plotly 可实现交互式探索
