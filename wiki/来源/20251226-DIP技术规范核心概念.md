# DIP技术规范核心概念

## 来源信息

- **原始文件**：`20251226按病种分值付费（DIP）技术规范的核心概念.docx`

- **主题**：DIP支付方式的技术规范和核心概念

## 核心概念

### DIP 分组原理

- 基于大数据对疾病诊断和手术操作进行自然组合
- 每一组合形成一个 DIP 病种
- 通过聚类算法发现规律性组合

### 关键指标

| 指标 | 说明 |
|------|------|
| DIP 分值 | 反映该病种的资源消耗相对权重 |
| 病种倍率 | 实际费用 / DIP分值付费标准 |
| 组内变异系数 | 衡量同病种费用的一致性 |
| 核心病种 | 例数较多的主要病种 |
| 综合病种 | 例数较少归并的病种 |
