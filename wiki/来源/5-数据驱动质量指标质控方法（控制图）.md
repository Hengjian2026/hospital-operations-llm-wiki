# 5-数据驱动质量指标质控方法（控制图）

## 来源信息

- **原始文件**：`raw/docx/5.数据驱动质量指标质控方法（控制图）.docx`
- **主题**：控制图在医疗质量管理中的应用

## 核心内容

### 控制图原理
控制图（Shewhart Control Chart）是美国管理大师休哈特提出的统计过程控制工具，用于判断生产流程是否处于控制状态。

**组成部分**：
- **上控制线（UCL）** / **下控制线（LCL）**：过程是否失控的判断依据
- **目标线（中心线）**：质量目标线

**失控判断规则**：
1. 超过控制线 → 立即失控
2. 七点原则：连续 7 点落在中心线上方或下方
3. 连续 3 点中有 2 点落在 2σ 限以外
4. 连续 6 点或更多点持续上升或下降（趋势）

### 控制图类型

| 数据类型 | 推荐控制图 |
|----------|-----------|
| 计量型（连续性）/ 子组数量多 | 均值-极差控制图（X̄-R） |
| 计量型（单点监测） | 个别值-移动极差控制图（X-Rm） |
| 计数型（缺陷数） | U chart |
| 计数型（缺陷率） | P chart |

### 医疗质控应用场景
- **感染率**监控 → U chart
- **死亡率**监控 → P chart
- **平均住院日**监控 → X̄-R chart（月度汇总）或 X-Rm chart（单病例）
- **医疗错误**监控 → U chart
- **急诊响应时间** → X-Rm chart
