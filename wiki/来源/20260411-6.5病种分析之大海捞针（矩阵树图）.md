# 核心内容摘要

1. **背景**: DRG(409组ADRG)/DIP2.0(9520组)涉及大量病种组合，具体到医院的病种统计工作繁重
2. **矩阵树图定义**: 通过嵌套矩形区域展示层级关系和数据占比，矩形面积反映占比
3. **与DRG/DIP的契合**: 层级表达契合DRG/DIP层层落组逻辑（主要诊断→内/外科→合并症）
4. **适用场景**: 面多成千上百组病种的统计，筛选超高/超低费用病种

---

# 矩阵树图特点

| 特点 | 说明 |
|------|------|
| **面积大小** | 例数越多，方格越大 |
| **颜色深浅** | 费用高低（可设置颜色渐变） |
| **层级结构** | 院区→科室→诊断代码 |
| **交互筛选** | 可按手术类型、费用区间筛选 |

---

# 制作要求

### D3.js 绘制规范

1. **层级结构**: 院区 → 出院科室 → 诊断代码
2. **颜色规则**: 住院费用高低（浅蓝→深红）
3. **标注内容**: 每个方格内显示病例数量
4. **标题**: "医院病案数据矩阵图例"
5. **交互**: "急诊手术"作为筛选项

### R Shiny 交互式绘制

1. **数据读取**: 读取Excel病案数据
2. **交互功能**: 按住院费用筛选，选择关注的费用区间
3. **目的**: 筛选出关注的病种
