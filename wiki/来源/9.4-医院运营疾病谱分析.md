# 医院运营疾病谱分析

## 来源信息

- **原始文件**：`raw/docx/9.4医院运营疾病谱分析.docx`
- **主题**：基于病案数据绘制疾病谱，结合盈亏分析识别优势/劣势病种
- **状态**：✅ 已摄入

## 核心内容

### 背景

在 DRG/DIP 付费改革背景下，医院有必要通过大数据分析院内主要诊断病种和主要手术病种，针对特定病种制定标准临床路径。

### 分析步骤

1. **数据预处理** — 异常值处理（费用超过 3 倍四分位差为超高/低病例）、缺失值处理
2. **按诊断频率绘制疾病谱**
3. **结合盈亏情况进行病种筛选**
4. **探索时间维度趋势**（月度/周度）

### 样例数据（10条 + 异常标记数据）

| 字段 | 说明 |
|------|------|
| 出院日期、医保类型 | 时间/分类维度 |
| 主要诊断编码/名称 | 疾病分类 |
| 手术操作编码/名称 | 手术分类 |
| 出院科室 | 科室维度 |
| 总费用、预测盈亏 | 度量指标 |

### 异常标记病例示例

| 诊断 | 科室 | 总费用 | 盈亏 |
|------|------|--------|------|
| 阵发性心房颤动-保守治疗 | 心血管内科二区 | 9,212 | -2,492 |
| 椎基底动脉综合征-保守治疗 | 神经内科一区 | 11,404 | -4,524 |
| 非胰岛素依赖型糖尿病-保守治疗 | 内分泌风湿免疫肾内科 | 21,453 | -5,760 |

### 盈利/亏损病种

**高盈利诊断**：经皮椎骨成形术、冠状动脉介入治疗、部分肿瘤治疗病例
**高亏损诊断**：部分重症肺炎、复杂手术、重症监护病例

**科室表现**：
- 盈利较好：心血管内科、眼科、部分外科
- 亏损压力：重症医学科、部分内科

### 管理建议

1. 优化病种结构，增加高盈利诊断收治比例
2. 针对高亏损病种进行成本效益分析
3. 强化科室发展，重点发展盈利能力强且符合医院战略的专科
4. 辅助流程优化，提高手术室和特殊治疗设备利用率
