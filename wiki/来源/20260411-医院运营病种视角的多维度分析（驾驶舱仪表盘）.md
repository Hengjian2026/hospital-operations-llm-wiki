# 核心内容摘要

1. **驾驶舱定义**: 对医院综合管理或专业监管指标的集中展示系统
2. **数据维度**: DIP分组、病种类型、倍率情况、性别、年龄、出院科室、住院信息、费用信息
3. **R Shiny仪表盘功能**:
   - 时间/科室筛选
   - 指标卡片展示（病例数、住院日、费用等）
   - Top10科室条形图（多指标切换）
   - Top10 DIP名称条形图
   - 年龄分布图、住院天数分布图
   - 离院方式饼图、医疗付费方式饼图
   - 费用结构饼图、病种类型饼图、倍率情况饼图

---

# 仪表盘功能模块

| 模块 | 内容 |
|------|------|
| 筛选功能 | 出院日期、出院科室 |
| 指标卡片 | 总病例数、平均住院日、总费用及各项明细 |
| 科室排名 | Top10科室（病例数/住院日/费用等多指标） |
| 病种排名 | Top10 DIP名称（多指标切换） |
| 患者特征 | 年龄分布、住院天数分布 |
| 构成分析 | 离院方式、付费方式、费用结构、病种类型、倍率 |
