# 核心内容摘要

1. **应用场景**: 分析报告中有很多分组比较的场景，如集团医院的两院区比较、科室之间比较、时间维度比较等
2. **图表工具**: 比较性图表是运营分析不可获缺的工具，简化复杂信息，直观展示比较对象的优劣
3. **金字塔图特点**:
   - 以 0 为中心，左右对称
   - 左侧代表主院区，右侧代表分院区
   - 用颜色区分不同院区
   - 每根柱末端标数值
4. **交互功能**: D3.js 绘制的 HTML 图表，支持下载 PNG 格式
5. **分析价值**: 可直观显示只在单院区设置的科室（金字塔只有一侧有数据），有利于医院进行科室设置决策

# 可视化要求

1. 横轴以 0 为中心，左右对称，刻度间隔 100（单位：千人）
2. 每根柱末端标数值，保留 1 位小数
3. 标题为"某医院2024年各科室门诊量金字塔图"
4. 图例放图形底部
5. 提供下载按钮，可下载 PNG 格式
