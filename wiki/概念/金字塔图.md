# 金字塔图

## 定义

金字塔图（Pyramid Chart）是一种以金字塔形状展示数据分布的比较性图表，以**0 为中心点左右对称**，常用于展示两组或多组数据之间的对比关系。

## 特点

- **对称结构**：以横轴 0 为中心，左右数据镜像分布
- **易于比较**：通过柱形长短直观展示数据差异
- **颜色区分**：用不同颜色区分对比的维度（如主院区 vs 分院区）
- **数值标注**：每根柱末端标注具体数值

## 应用场景

### 医院运营管理中的典型应用

| 场景 | 说明 |
|------|------|
| **两院区比较** | 展示同一科室在主院区与分院区的门诊量、住院量等对比 |
| **科室间比较** | 比较不同科室之间的某项指标（如门诊量、手术量） |
| **时间维度比较** | 展示同一指标在不同时间点的变化 |
| **目标与实际对比** | 展示预算目标与实际完成情况的差距 |

## 制作要求

### D3.js 绘制规范

1. **横轴设置**：以 0 为中心，左右对称，刻度间隔一致（通常为 100 或指定单位）
2. **颜色区分**：左右两侧用不同颜色（如蓝色 vs 橙色）区分对比维度
3. **数值标注**：每根柱末端保留 1 位小数
4. **标题**：清晰描述图表内容，如"某医院2024年各科室门诊量金字塔图"
5. **图例**：放在图形底部，说明颜色含义
6. **交互功能**（可选）：支持下载 PNG 格式

## 示例数据

| 科室 | 主院区 | 分院区 |
|------|--------|--------|
| 儿科 | 7297 | 14948 |
| 妇科 | 8355 | 9763 |
| 骨伤 | 6589 | 5157 |
| 皮肤 | 7245 | 5022 |

## 解读方法

1. **柱形长短**：直接反映数值大小
2. **左右对比**：同一科室在两侧的长度差异表示对比维度的差距
3. **单侧存在**：只有一侧有数据的科室表示该业务仅在对应院区开展
4. **整体分布**：可观察哪些科室是主力科室（全院占比高）

## 优缺点

| 优点 | 缺点 |
|------|------|
| 直观展示对比差异 | 仅适用于两组数据对比 |
| 可识别单侧数据（特殊科室） | 数据量过多时不够清晰 |
| 形式美观，易于理解 | 不适合展示时间趋势 |
