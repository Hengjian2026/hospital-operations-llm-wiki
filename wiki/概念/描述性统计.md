# 描述性统计

## 概念

描述性统计是对数据的基本特征进行汇总和描述的统计方法。在医院运营分析中，用于刻画费用、住院天数、盈亏金额等定量指标的分布特征。

## 核心指标

| 指标 | 含义 | 医院分析中的应用 |
|------|------|----------------|
| 均值 (Mean) | 数据的平均值 | 平均住院日、平均费用 |
| 中位数 (Median) | 数据排序后的中间值 | 盈亏金额典型水平（不易受极端值影响） |
| 众数 (Mode) | 出现次数最多的值 | 最常见费用区间 |
| 最大值 / 最小值 | 数据的极端边界 | 识别异常高费用病例 |
| 四分位数 | 数据的25%/75%位置 | 箱线图构建 |
| 标准差 | 数据的离散程度 | 费用波动分析 |

## 异常值识别

常用方法：

1. **箱线图法**：小于 Q1-1.5×IQR 或大于 Q3+1.5×IQR 的值为异常值
2. **标准差法**：超过均值 ±3 标准差的值为异常值
3. **Z-score 法**：Z > 3 或 Z < -3 为异常值

异常值在医院运营中的含义：
- 极高费用病例：可能是医疗质量问题或特殊并发症
- 极低费用病例：可能是数据缺失或异常出院
- 极大/小住院天数：反映诊疗效率异常

## 分析步骤定位

病种盈亏分析的六个步骤中，描述性统计是**第二步**（在数据清洗之后），用于建立对盈亏金额分布的直觉认知。参见 [[方法论/病种盈亏分析]]。
