# 控制图

## 概念

控制图（Control Chart）是一种时序质量监控工具，通过设定控制限来识别过程中的异常波动。在医院运营分析中，用于监控医疗质量指标的稳定性。

## 核心原理

### 控制限计算

| 线条 | 计算公式 | 含义 |
|------|---------|------|
| 中心线 (CL) | 所有数据的均值 | 长期平均水平 |
| 上控制限 (UCL) | CL + 3σ | 正常波动上限 |
| 下控制限 (LCL) | CL - 3σ | 正常波动下限 |
| 警戒线 | CL ± 2σ | 早期预警区域 |

### 3σ 原则

根据正态分布特性：
- 99.73% 的数据应落在 μ ± 3σ 范围内
- 超出控制限的点概率极小（约 0.27%），视为异常

## 图表解读

### 正常模式

- 点在控制限内
- 点在中心线两侧随机分布
- 无连续异常趋势

### 异常模式识别

| 异常模式 | 图形特征 | 含义 |
|---------|---------|------|
| **界外点** | 点超出 UCL 或 LCL | 突发异常，需立即调查 |
| **连绞模式** | 连续7点在中心线同一侧 | 过程偏移，趋势变化 |
| **趋势模式** | 连续7点上升或下降 | 持续改善或恶化 |
| **周期模式** | 周期性起伏 | 存在周期性因素 |
| **趋紧模式** | 波动逐渐变小 | 控制过严或改进成功 |
| **层别模式** | 多批数据均值差异大 | 批次间存在系统性差异 |

### 8条判异准则

为更灵敏地识别异常，现代质量管理常用8条判异准则：

1. 1点落在 A区以外
2. 连续9点落在中心线同一侧
3. 连续6点递增或递减
4. 连续14点交替上下
5. 连续3点中有2点在 A区
6. 连续5点中有4点在 B区
7. 连续15点落在 C区
8. 连续8点落在 C区以外

## 应用场景

- **医疗质量安全** [[来源/20251229-公立医院绩效考核分析报告]] — 医疗质量安全指标监控
- **手术并发症率** — 术后并发症发生率趋势
- **抗菌药物使用强度** — DDDs 监测
- **住院病死率** — 低风险组死亡率异常识别
- **平均住院日** — 住院效率波动监控

## 控制图类型选择

| 类型 | 适用数据 | 控制限计算 |
|------|---------|-----------|
| X̄-R 图 | 计量型数据（连续值） | 基于子组极差 |
| X̄-S 图 | 大样本计量数据 | 基于标准差 |
| p 图 | 比例/率数据（如并发症率） | 基于二项分布 |
| u 图 | 单位缺陷数（如感染率） | 基于 Poisson 分布 |

## 实施步骤

1. **确定监控指标**：选择需要监控的关键质量指标
2. **收集历史数据**：建立基线数据（建议 n ≥ 20）
3. **计算控制限**：CL = 均值，UCL/LCL = 均值 ± 3σ
4. **绘制控制图**：时序排列，标注控制限
5. **分析异常模式**：应用判异准则识别异常
6. **持续监控**：定期更新数据，动态调整控制限
