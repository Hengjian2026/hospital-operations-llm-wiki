# 森林图

## 定义

森林图（Forest Plot）是一种统计图表，以**统计指标（均值、方差）**和**统计分析方法（方差分析）**为基础，用数值运算结果绘制而成。常用于流行病学统计研究（如 Meta 分析），可同时展示多项研究的汇总结果。

## 核心元素

| 元素 | 说明 |
|------|------|
| **点估计值** | 用圆点表示效应量的点估计（如均值、中位数） |
| **置信区间** | 用横线段表示 95% 置信区间（CI） |
| **无效线** | 垂直虚线，通常在 0 或 1 处（取决于效应量类型） |
| **样本量/权重** | 通常用方块大小或线条粗细表示 |
| **四分位距 (IQR)** | 用于偏态分布数据（中位数 + IQR 形式） |

## 两种主要形式

### 1. 均值 + 95% CI

- **适用场景**：正态分布、大样本数据
- **解读**：置信区间越窄，估计越精确

### 2. 中位数 + IQR（四分位距）

- **适用场景**：偏态分布、小样本数据
- **优势**：抗异常值干扰，更具代表性

## 应用场景

### 医院运营管理中的典型应用

| 场景 | 说明 |
|------|------|
| **病种费用比较** | 比较不同 DIP/DRG 分组的住院费用差异 |
| **科室间费用对比** | 展示同一病种在不同科室的费用差异 |
| **时间趋势分析** | 监测病种费用随时间的变化 |
| **医师绩效对比** | 比较不同医师的同病种费用 |
| **异常值识别** | 识别置信区间不重叠的异常病种组 |

## 统计学意义判断

- **置信区间不重叠**：两组差异有统计学意义
- **置信区间与无效线相交**：差异不明确
- **置信区间完全在无效线一侧**：差异有统计学意义

## R/Shiny 交互式森林图制作要求

```r
# 核心要求
1. 效应量计算：以分组变量（如DIP分组）为分组，效应变量（如总费用）计算95%CI
2. 图例结构：左侧均值条形图 + 右侧均值比较图
3. 交互筛选：支持按科室、时间（月份）筛选
4. 颜色区分：不同分组变量用不同颜色/符号区分
5. 标题：清晰描述如"各科室病种平均费用分组比较森林图"
```

## 优缺点

| 优点 | 缺点 |
|------|------|
| 信息密度高（同时展示多种统计量） | 需要一定统计学基础才能解读 |
| 可直观判断统计学意义 | 对偏态数据需选择合适指标 |
| 适合汇总比较多项研究/分组 | 交互实现需要编程能力 |

## 在医保支付标准制定中的应用

森林图可以帮助医院管理者：
1. **识别异常病种组**：费用显著高于或低于平均水平的病种
2. **支持价格谈判**：为与医保部门的支付标准谈判提供数据依据
3. **成本管控**：发现成本过高的病种组，制定控费措施
4. **最佳实践分享**：通过科室间对比，识别最佳实践科室
