# 箱线图

## 概念

箱线图（Box Plot）通过四分位数展示数据分布，并直观识别异常值。是描述性统计和异常值识别的重要可视化工具。

## 图表结构

```
        ● 异常值
         |
  |-----●-----|
  |     |     |
----|-----|-----|----
  LCL  Q2    UCL
   |  (中位数)  |
   |           |
   须 = 1.5×IQR   |
   LCL = Q1-1.5×IQR  |
   UCL = Q3+1.5×IQR  |
                     |
                 箱体 = IQR (Q3-Q1)
                 Q1 = 第25百分位数
                 Q3 = 第75百分位数
```

### 核心概念

| 元素 | 计算方法 | 含义 |
|------|---------|------|
| 箱体 | Q3 - Q1 = IQR | 中间50%数据的分布范围 |
| 中位数 | Q2 (50百分位) | 代表性水平，不受极端值影响 |
| 上须 | Q3 + 1.5×IQR | 正常值上界 |
| 下须 | Q1 - 1.5×IQR | 正常值下界 |
| 异常值 | <下须 或 >上须 | 需关注的极端值 |

## 异常值判断标准

### 1.5×IQR 法则（最常用）

$$\text{异常值} \begin{cases} < Q1 - 1.5 \times IQR \\ > Q3 + 1.5 \times IQR \end{cases}$$

### 异常程度分级

| 级别 | 条件 | 图形表示 |
|------|------|---------|
| 轻度异常 | Q1-1.5×IQR < x < Q1-3×IQR | ○ 空心圆 |
| 重度异常 | < Q1 - 3×IQR 或 > Q3 + 3×IQR | ● 实心圆 |

## 应用场景

- **病种费用异常识别** [[来源/4-病种分析基于数据的异常值查找]] — 识别极高/极低费用病例
- **盈亏金额分布** [[来源/20251206-病种盈亏探索分析一]] — 盈亏分布特征
- **科室费用对比**：多个科室费用分布并排比较
- **住院日异常**：识别超长/超短住院病例

## 箱线图 vs 小提琴图

| 特性 | 箱线图 | 小提琴图 |
|------|--------|----------|
| 分布形状 | 仅中位数和四分位 | 完整密度分布 |
| 多峰识别 | 不能 | 能 |
| 尾部信息 | 不展示 | 展示 |
| 适用场景 | 简单对比、快速概览 | 复杂分布对比、形态分析 |

## 制作注意事项

1. **数据量**：样本量过小时箱线图意义有限（建议 n ≥ 20）
2. **分类比较**：多组并排绘制时保持箱体宽度一致
3. **坐标轴**：从0开始避免误导（若数据不含0）
4. **标注**：标注中位数数值和样本量

## 医院场景解读

- **极高费用**：可能是高值耗材、危急重症、并发症
- **极低费用**：可能是数据缺失、自动出院、分解住院
- **超长住院日**：诊疗效率问题或压床
- **超短住院日**：门诊治疗即可或分解住院
