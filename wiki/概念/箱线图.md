# 箱线图

## 概念

箱线图（Box Plot）通过四分位数展示数据分布，并直观识别异常值。

## 图表结构

```
  |-----●-----|
  |     |     |
----|-----|-----|----
  LCL   Q2   UCL
        |
       中位数
       箱体 = IQR (Q3-Q1)
       须 = 1.5 × IQR
       ● = 异常值
```
