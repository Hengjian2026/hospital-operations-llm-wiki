# 绩效考核体系

## 概述

公立医院绩效考核体系是基于国家政策要求，对医院运营、医疗质量、服务效率等方面进行综合评估的管理系统。

## 核心维度

来自 [[来源/20251229-公立医院绩效考核分析报告]] 的六维度框架：

| 维度 | 主要指标 |
|------|----------|
| 总体运营 | 门诊人次、出院人次、手术量、医疗收入 |
| 服务能力 | 日间手术率、微创手术率、四级手术率、门诊住院比 |
| 质量安全 | 手术并发症率、切口感染率、抗菌药物使用强度 |
| 运营效率 | 床位使用率、床位周转率、医师工作负荷 |
| 财务经济 | 收入结构、成本构成、人力成本占比 |
| 学科人才 | 紧缺科室配置（麻醉、儿科、重症、病理、中医） |

## 可视化工具

- 仪表盘：目标完成率一屏展示
- 雷达图：科室竞争力多维对比
- 瀑布图：成本累积分析
- 气泡矩阵：单病种质效四维分析
- 趋势图：三年指标变化
