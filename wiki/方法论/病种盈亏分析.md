# 病种盈亏分析

## 概述

病种盈亏分析是以单个病种（或DRG/DIP分组）为单位，分析该病种的实际成本与收入之间的差额，是按病种付费改革背景下的核心分析内容。

## 分析步骤

参见 [[来源/20251206-病种盈亏探索分析一]]：

1. **数据清洗** — 处理缺失值、分类变量
2. **描述性统计** — 盈亏金额的分布特征
3. **相关性分析** — 影响因素探索
4. **分类对比** — 性别、科室、年龄、住院天数、费用结构
5. **回归分析** — 定量影响因素建模
6. **机器学习** — 预测模型构建

## 核心指标

| 指标 | 说明 |
|------|------|
| 盈亏金额 | 实际费用 - DIP/DRG付费标准 |
| 盈亏率 | 盈亏金额 / 付费标准 |
| 病种倍率 | 实际费用 / 付费标准 |
| 组内变异系数 | 同病种费用离散程度 |

## 关键影响因素

- 平均住院日
- 药占比、耗占比
- 手术与非手术
- 患者特征（年龄、性别）
- 科室类型
