# 指标体系

## 概述

本文档汇总医院运营分析中常用的核心指标，为分析报告提供标准化定义参考。

## 门诊指标

| 指标 | 定义 |
|------|------|
| 门诊人次 | 一定时期内的门诊患者总数 |
| 门诊收入 | 门诊业务带来的医疗收入 |
| 挂号数 | 门诊挂号总量 |

## 住院指标

| 指标 | 定义 |
|------|------|
| 出院人次 | 一定时期内的出院患者总数 |
| 开放床位数 | 医院实际开放的床位总数 |
| 床位使用率 | 实际占用床日 / 实际开放床日 |
| 床位周转次数 | 出院人次 / 平均开放床位数 |
| 平均住院日 | 出院患者占用总床日数 / 出院人次 |

## 手术指标

| 指标 | 定义 |
|------|------|
| 手术量 | 一定时期内的手术总例数 |
| 日间手术率 | 日间手术例数 / 手术总例数 |
| 微创手术率 | 微创手术例数 / 手术总例数 |
| 四级手术率 | 四级手术例数 / 手术总例数 |

## DRG/DIP 指标

| 指标 | 定义 |
|------|------|
| CMI | 病例组合指数 = 总权重 / 总病例数 |
| 盈亏金额 | 实际费用 - 付费标准 |
| 病种倍率 | 实际费用 / 付费标准 |
| 组内变异系数 | 同组费用标准差 / 均值 |

## 财务指标

| 指标 | 定义 |
|------|------|
| 医疗收入 | 门诊收入 + 住院收入 |
| 药占比 | 药品收入 / 医疗收入 |
| 耗占比 | 耗材收入 / 医疗收入 |
| 人力成本比 | 人力成本 / 总成本 |

## 质量指标

| 指标 | 定义 |
|------|------|
| 手术并发症率 | 并发症病例 / 手术总例数 |
| 切口感染率 | 感染病例 / 手术总例数 |
| 抗菌药物使用强度 | DDDs / 收治患者人天数 × 100 |

## 数据来源

- 医院绩效考核系统
- 医保结算数据
- 病案首页数据
