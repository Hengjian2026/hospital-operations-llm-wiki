# 可视化图表类型

## 概述

医院运营分析中常用的可视化图表类型及其适用场景。

## 趋势分析

| 图表 | 适用场景 |
|------|----------|
| 折线图 | 指标随时间变化趋势（三年趋势） |
| 面积图 | 收入结构演变 |
| 柱形图 | 分年度/分科室对比 |

## 比较分析

| 图表 | 适用场景 |
|------|----------|
| 柱形图 | 科室间/病种间单指标对比 |
| 堆叠柱形图 | 构成比较（收入结构、成本结构） |
| 雷达图 | 多维度竞争力对比（紧缺科室配置） |
| 森林图 | 多指标综合对比 |
| 金字塔图 | 分组比较（年龄分层） |

## 分布分析

| 图表 | 适用场景 |
|------|----------|
| 箱线图 | 费用分布与异常值 |
| 小提琴图 | 多组费用分布对比 |
| 直方图 | 单变量分布 |
| 热力图 | 二维分布（科室×时间） |
| 旭日图 | 多层级构成（病种分类） |

## 关系分析

| 图表 | 适用场景 |
|------|----------|
| 散点图 | 两指标关联（住院日 vs 费用） |
| 气泡图 | 三维关系（住院日+费用+病例数） |
| 矩阵树图 | 构成占比（病种分布） |

## 进度/完成率

| 图表 | 适用场景 |
|------|----------|
| 仪表盘 | 目标完成率一屏展示 |
| 进度条 | 单指标完成进度 |
| 组合图 | 多种图形叠加 |

## 构成分析

| 图表 | 适用场景 |
|------|----------|
| 饼图/复合饼图 | 单一构成比例 |
| 堆叠柱形图 | 多期构成对比 |
| 瀑布图 | 成本累积贡献 |
| 旭日图 | 多层级构成 |

## 质量监控

| 图表 | 适用场景 |
|------|----------|
| 控制图 | 指标时序监控（质量控制线） |
| 帕累托图 | 主要因素排序 |
